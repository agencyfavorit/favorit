# favorit.agency

Сайт IT-агентства «Фаворит»: одна страница на двух языках (`/` и `/en/`), юридические страницы и 404.

**Стек:** Astro 7 · TypeScript (strictest) · чистый CSS с каскадными слоями · ни одной клиентской библиотеки.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm install` | зависимости (Node ≥ 22.23, см. `.nvmrc`) |
| `npm run dev` | дев-сервер на `localhost:4321` |
| `npm run build` | проверка типов + сборка в `dist/` |
| `npm run preview` | локальный просмотр собранной версии (CSP работает только здесь) |
| `npm run icons` | перегенерировать PNG-иконки и `favicon.ico` из `src/assets/brand/app-icon.svg` |

Деплой — Netlify из ветки `main`, настройки в `../netlify.toml`.

## Где что лежит

```
src/
  config/site.ts      контакты, реквизиты, адрес формы — единый источник
  i18n/               тексты: types.ts (схема), ru.ts, en.ts
  components/
    sections/         разделы главной в порядке появления
    ui/               Button, Icon, Logo, Wordmark (надпись в скобках), Ghost
  layouts/            Base (head, SEO, шрифты), Legal
  views/HomePage.astro  сборка главной из разделов
  pages/              маршруты: /, /en/, /privacy/, /offer/, 404
  scripts/            клиентский TypeScript: шапка, вкладки, форма
  lib/                типографика, геометрия надписи, картинки, schema.org
  styles/global.css   токены, сброс, базовая типографика
```

## Как менять

- **Текст** — только в `src/i18n/ru.ts` и `en.ts`. Схема в `types.ts`: если в одном языке не хватает строки, сборка упадёт на проверке типов.
- **Переносы в заголовках** — `\n` в строке словаря. Неразрывные пробелы после предлогов и перед тире расставляет `lib/typo.ts`, вручную не нужно.
- **Картинки** — исходники в `src/assets/images/` (JPEG высокого качества). AVIF/WebP/JPEG нужных размеров Astro делает при сборке; качество по кодекам — в `astro.config.mjs`.
- **Надпись в скобках** (`[ФАВОРИТ]`, бледные заголовки) — SVG с точной шириной, без JS. Для нового слова ширина посчитается по метрикам глифов в `lib/wordmark.ts`.

## Качество

- Lighthouse 100/100/100/100 на телефоне и десктопе, оба языка; CLS 0.
- CSP с хэшами для каждого скрипта и стиля (Astro `security.csp`) + заголовки безопасности Netlify.
- Шрифты Wix Madefor (OFL) раздаются со своего домена, с подогнанным под метрики запасным шрифтом.
- Без JS сайт полностью работает: меню-якоря, FAQ на `<details>`, принципы списком, форма — обычный POST.
- `prefers-reduced-motion`, видимый фокус, skip-link, `inert` под открытым меню, ARIA-вкладки.
